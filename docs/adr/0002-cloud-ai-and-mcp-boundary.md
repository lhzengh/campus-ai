# ADR-0002：云端模型 API 与 MCP 边界

- 状态：接受
- 日期：2026-08-19

## 背景

系统需要每天稳定、无人值守地分析消息。用户选择云端 AI，并希望保留 API 或 MCP 的扩展可能。

## 决定

MVP由服务端直接调用OpenAI兼容云端模型API，输出必须通过JSON Schema和Pydantic校验。提供者由Base URL、模型名和密钥配置，不绑定具体厂商。

MCP不承担模型推理，也不进入MVP。未来若需要让外部AI客户端查询消息或调用待办操作，再将Campus AI作为MCP Server暴露受限资源与工具。

## 后果

每日任务不依赖外部AI宿主在线，调用、用量和失败重试均可审计。密钥不得写入数据库日志、代码或Markdown。
