# ADR-0003：来源访问与认证策略

- 状态：接受
- 日期：2026-08-19

## 决定

来源使用统一适配器。静态页面优先HTTPX与selectolax，只有JavaScript或认证流程确有需要时才使用Playwright。所有适配器必须限速、增量采集并保留来源链接。

统一认证由用户在可见浏览器中完成，会话状态加密保存。系统不自动破解验证码、不绕过访问控制。公众号优先官方/授权接口、RSS、邮件或允许访问的公开页面；没有稳定路径时降级为用户手动分享。

## 后果

来源变化只影响对应适配器。部分公众号可能无法全自动接入，这是验证阶段允许得出的“不可行”结论，而不是通过高风险抓取规避。
