# ADR-0005：来源与凭据必须运行时配置

- 状态：接受
- 日期：2026-08-21

## 背景

Campus AI 的目标是服务不同学校和信息来源。当前某个部署实例的目标门户不应演变为产品级依赖，也不能让网站、账号或凭据进入代码、镜像、客户端和公开文档。

## 决定

- 核心仓库只包含通用来源接口、适配器和脱敏测试夹具，不包含具体学校名称或真实入口地址。
- 站点 URL、允许域名/路径、解析选择器和账号引用由运行时来源配置提供。
- 密码、验证码、Cookie、Token、数据库密码、AI Key 和推送密钥由外部 Secret 提供，不保存到普通来源配置。
- URL 不得内嵌 `userinfo` 凭据。服务端与客户端缺少必需端点或数据库配置时应明确失败，不回退到某个预设站点或默认密码。
- 测试只使用 RFC 保留示例域名、Mock 传输或运行时生成的临时凭据。
- 具体实例的运维记录保存在仓库外；确需本地 Markdown 时使用已忽略的 `docs/private/`。

## 后果

部署者需要在启动前显式提供配置和 Secret，初次启动步骤比使用默认凭据多，但可以避免项目绑定单一学校、误连错误环境或把秘密提交到 Git。新增学校时应增加配置或独立适配逻辑，而不是修改通用常量。
